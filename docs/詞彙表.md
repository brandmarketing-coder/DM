# 詞彙表

這個專案的文件和回報裡會用到的術語，每個附一句白話解釋。依類別排列，同類內依筆畫／字母。

## 網站與發布

| 術語 | 白話解釋 |
|---|---|
| GitHub | 存放程式碼的網路服務，每次修改都會留下紀錄，可以隨時回到舊版本 |
| GitHub Pages | GitHub 免費提供的網站空間；把檔案推上去，網址就會自動更新（約 1～2 分鐘） |
| repo（儲存庫） | 一個專案在 GitHub 上的「資料夾」，包含所有檔案和修改歷史。本專案是 `brandmarketing-coder/DM` |
| commit（提交） | 把這次的修改存成一個紀錄點，附一句說明。之後可以查「誰在什麼時候改了什麼」 |
| push（推上去） | 把電腦上的 commit 上傳到 GitHub；推上去後網站才會更新 |
| main（主分支） | 正式版的那一條修改紀錄線；網站顯示的就是 main 的內容 |
| 轉址 | 打開 A 網址時自動跳到 B 網址。最外層的 `index.html` 會把人帶到 `Coding/` |
| CDN | 放常用程式庫的公共下載站（本專案用 cdnjs、jsDelivr、Google Fonts），網頁執行時從這裡載入工具 |
| 延遲載入 | 用到時才下載，不在一開網頁就下載，讓網頁開得比較快。例如匯出工具按下匯出才載入 |
| 快取（cache） | 瀏覽器把下載過的檔案暫存起來，下次直接用舊的，所以有時更新了卻看到舊畫面 |
| 快取破解（`?v=數字`） | 在檔名後面加版本號，檔案一更新數字就變，瀏覽器會當成新檔重新下載 |

## 檔案與資料格式

| 術語 | 白話解釋 |
|---|---|
| CSV | 用逗號分隔的表格文字檔，Excel 可以開。本專案的文案表就是 CSV |
| UTF-8 | 一種文字編碼方式。CSV 存成別的編碼，中文會變亂碼，所以要存 UTF-8 |
| xlsx | Excel 檔案格式 |
| WebP | 一種圖片格式，畫質和 PNG 差不多但檔案小很多，支援透明背景（去背） |
| SVG | 用文字描述的向量圖，放大不會模糊；編輯區的圖示按鈕就是 SVG |
| dataURL | 把整張圖片轉成一長串文字直接塞進網頁裡，不用另外存檔。上傳的 QR 圖片就是這樣存的 |
| Blob | 瀏覽器記憶體裡的一份檔案內容（還沒存到硬碟）。匯出的 JPG／PDF 先做成 Blob 再交給使用者 |
| id | 每筆資料的唯一名稱。本專案商品的 id＝圖片檔名（去掉副檔名），例如 `咖啡因養髮液100mL` |
| null | 「沒有值」。流程步驟的品名是 null 時，代表「自動帶入」 |
| copyKey | 商品對應到文案表的那個官網名稱，用來找介紹、用途、價格 |

## 程式結構

| 術語 | 白話解釋 |
|---|---|
| 函式（function） | 一段有名字、可以重複呼叫的程式，例如 `renderDM()` 負責重畫 DM |
| state | 存放「目前編輯中所有內容」的那包資料；畫面都是依它畫出來的 |
| 類別圖（class diagram） | 用方框和箭頭畫出「資料長什麼樣、彼此怎麼關聯」的圖。見 [專案地圖](專案地圖.md) |
| Mermaid | 一種用文字畫圖的寫法；GitHub 看 `.md` 檔時會自動把它畫成圖 |
| 程式庫（library） | 別人寫好、拿來直接用的工具程式，例如 html2canvas、jsPDF |
| html2canvas | 程式庫：把網頁上的 DM 拍成一張圖片（匯出 JPG 的核心） |
| jsPDF | 程式庫：把圖片包成 PDF 檔 |
| qrcode-generator | 程式庫：把網址轉成 QR Code 圖案 |
| 底圖代號 | 每張底圖在程式裡的短名稱，例如 `portrait`（直式）、`p3`（流程）、`h1`（橫式 1） |

## 版面與樣式

| 術語 | 白話解釋 |
|---|---|
| 版面（layout） | DM 的排法：四格、兩格、一格、流程 |
| 防破版／自動縮放 | 內容太多放不下時，程式自動依序縮小說明字、品名、商品圖，讓所有字都放得進去、不被切掉 |
| 溢出 | 內容超出它的框，會被切掉或壓到別的東西 |
| 內距（padding） | 框線和裡面文字之間的空白 |
| 行距（line-height） | 一行字佔的高度；數字越小，行與行越擠 |
| 字級 | 字的大小，本專案多用 px（像素）表示 |
| 粗細（font-weight） | 字的粗細：400＝一般（Normal）、500 以上＝偏粗、200＝很細 |
| 色碼（例如 `#19322F`） | 用 6 個英數字表示一個顏色；`#19322F` 是品牌墨綠 |
| 字型子集 | 只下載用得到的字（例如只有數字 0～9 和 $），檔案只有幾 KB |
| 預覽縮放 | 編輯器把 A4 大小的 DM 縮小放進螢幕；匯出時會恢復原尺寸 |

## 手機與匯出

| 術語 | 白話解釋 |
|---|---|
| 觸控裝置 | 用手指操作的手機、平板。編輯器偵測到時會改用手機原生的選單、放大按鈕 |
| 內建瀏覽器 | 在 LINE、FB、IG 裡點連結時開的瀏覽器，常常不允許下載檔案 |
| 使用者手勢 | 「使用者真的點了一下」這件事。瀏覽器只允許在點擊當下開新頁或下載，等太久就會被擋 |
| Web Share（系統分享） | 呼叫手機內建的分享面板；iPhone 的分享面板裡有「儲存影像」 |
| WebKit | Safari 的網頁核心；iPhone 上的 Chrome、LINE 也都用它，所以 iPhone 的下載問題各瀏覽器一致 |

## 測試與驗證

| 術語 | 白話解釋 |
|---|---|
| 壓測 | 故意塞最長的文字、最多的商品，看版面會不會壞掉 |
| 回歸測試 | 改了 A 之後，重新檢查原本正常的 B、C 有沒有被改壞 |
| 組合測試 | 把底圖×版面×語言的所有組合都跑一遍，例如「51 組合」 |
