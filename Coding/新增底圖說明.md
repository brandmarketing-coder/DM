# 新增底圖流程

底圖無 build 工具，全部於 `Coding/index.html` 手動設定。以下以新代號 `h5`（橫式範例）說明；直式滿版用 `p` 開頭代號（如 `p3`）。

## 1. 圖檔（放 `沙龍DM公版/`）

1. 底圖本體：滿版 A4 設計圖，保留白色內容區。橫式約 3508×2480、直式約 2480×3508。檔名自訂，例：`新底圖橫式.jpg`。
2. 選單縮圖：`th-h5.jpg`，約 10KB 的縮小圖。選單只載此縮圖。

## 2. `Coding/index.html` 設定

1. `LAND_BG` 物件加一筆：`h5: '../沙龍DM公版/新底圖橫式.jpg'`
2. `LAND_POS` 物件加一筆內容區座標：`h5: { left, top, right, bottom }`。四值為白色內容區四邊距佔整張圖的百分比。
3. `isLandscape()` 的陣列：橫式底圖加入 `'h5'`（決定 A4 橫式尺寸與匯出方向）。直式滿版底圖不加入。
4. `isFeatureTwo()` 的陣列：兩格版要用「單品放大＋描述」樣式則加入 `'h5'`；要用「主商品＋贈品」樣式則不加。
5. 選單 HTML（`<div class="bg-pick">` 內）複製一個底圖選項：
   ```html
   <div class="bg-opt" id="bg-h5" onclick="setBg('h5')">
     <img src="../沙龍DM公版/th-h5.jpg" alt="名稱" decoding="async" fetchpriority="low">
     <div class="bg-label">名稱</div>
   </div>
   ```
6. `setBg()` 內的 active 切換陣列 `['portrait','p2','h1','h2','h3','h4']` 加入 `'h5'`。
7. UI 翻譯：`UI` 物件的 `zh` / `en` / `pl` 三區各加一筆 `bgH5: '...'`。
8. `applyStaticUI()` 內加一行：`set('#bg-h5 .bg-label', t('bgH5'));`

## 3. 選配

- 白色內容區較小、要停用四格：於 `setBg()` 的 `noFour` 條件加入該代號。
- 版面微調（分隔線、特寫尺寸等）：新增 `#dm-sheet.bg-h5 { ... }` CSS 規則。

## 4. 快取

底圖本體與縮圖的 URL 不帶 `?v=` 版本號。沿用新檔名；若同名覆蓋，需自行處理瀏覽器快取。

## 5. 驗證

切換新底圖，分別測四格／兩格／一格 × 中／英／波蘭，確認內容不溢出白框；並檢查手機版。
