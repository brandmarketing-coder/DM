# 新增底圖流程

底圖無 build 工具，全部於 `Coding/index.html` 手動設定。以下以新代號 `h5`、選單名稱「秋季橫式」（橫式範例）說明；直式滿版用 `p` 開頭代號（既有 `p2`、`p3`，下一個為 `p4`）。

## 1. 圖檔（放 `沙龍DM公版/直式/` 或 `沙龍DM公版/橫式/`）

**檔名＝編輯器選單上顯示的名稱**（不含空格，例：選單「橫式 1」→ `橫式1.jpg`）。

1. 底圖本體：滿版 A4 設計圖，保留白色內容區。橫式約 3508×2480、直式約 2480×3508。
   放 `沙龍DM公版/橫式/秋季橫式.jpg`（直式則放 `沙龍DM公版/直式/`）。
2. 選單縮圖：約 10KB 的縮小圖，**與底圖同名**，放同方向資料夾下的 `縮圖/`：
   `沙龍DM公版/橫式/縮圖/秋季橫式.jpg`。選單只載此縮圖。

```
沙龍DM公版/
├─ 直式/   直式-頁首.jpg、直式-頁尾.jpg、大促直式.jpg、流程.jpg
│  └─ 縮圖/   大促直式.jpg、流程.jpg
└─ 橫式/   橫式1.jpg、橫式2.jpg、橫式3.jpg、大促橫式.jpg
   └─ 縮圖/   橫式1.jpg、橫式2.jpg、橫式3.jpg、大促橫式.jpg
```

## 2. `Coding/index.html` 設定

1. `LAND_BG` 物件加一筆：`h5: '../沙龍DM公版/橫式/秋季橫式.jpg'`
2. `LAND_POS` 物件加一筆內容區座標：`h5: { left, top, right, bottom }`。四值為白色內容區四邊距佔整張圖的百分比。
3. `BG_LIST` 陣列加一筆（陣列順序＝選單顯示順序）：`{ id: 'h5', orient: 'l', thumb: '橫式/縮圖/秋季橫式.jpg', label: 'bgH5' }`。`thumb` 為相對於 `沙龍DM公版/` 的路徑。`orient` 橫式為 `'l'`、直式為 `'p'`，決定選單分組、A4 尺寸與匯出方向。
4. `isFeatureTwo()` 的陣列：兩格版要用「單品放大＋描述」樣式則加入 `'h5'`；要用「主商品＋贈品」樣式則不加。
5. UI 翻譯：`UI` 物件的 `zh` / `en` / `pl` 三區各加一筆 `bgH5: '...'`。

## 3. 選配

- 白色內容區較小、要停用四格：於 `setBg()` 的 `noFour` 條件加入該代號。
- 版面微調（分隔線、特寫尺寸等）：新增 `#dm-sheet.bg-h5 { ... }` CSS 規則。

## 4. 快取

底圖本體與縮圖的 URL 不帶 `?v=` 版本號。沿用新檔名；若同名覆蓋，需自行處理瀏覽器快取。

## 5. 驗證

電腦版於對應分組下拉、手機版於對應分組列選取新底圖，分別測四格／兩格／一格 × 中／英／波蘭，確認內容不溢出白框。
