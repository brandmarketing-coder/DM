# 變更紀錄撰寫規則

檔案：`docs/變更紀錄.md`（repo 根目錄 `C:\Users\oright\Desktop\沙龍\DM`）

## 何時寫

- 每完成一步改動，在該步 commit 之前新增一條；一步只寫一條。
- 該步沒有修改任何檔案時不寫。

## 寫在哪裡

- 依月份分節，節標題為 `## YYYY-MM`。
- 月份節由新到舊排列，最新的月份節緊接在開頭時間軸區塊之後。
- 該月份節不存在時，新增於所有月份節之上。
- 同一月份節內，新條目放在最上面。

## 條目格式

- 格式：`- **M/D｜標題**：內容。`
- 日期用當天日期。
- 標題：一個短句，說明做了什麼。該步對應 `Coding/Roadmap.md` 的新版本號時，標題後加 `（vX.Y）`。
- 內容：1～2 句白話，寫「做了什麼、結果是什麼」。
- 不寫程式細節（函式名稱、樣式屬性、變數名稱）。
- 第一次出現的技術術語，括號內附一句白話解釋，並依 `docs-glossary` 規則收進詞彙表。
- 不寫人名與內部對話內容（網站公開）。

## 開頭時間軸

- 時間軸只在出現新的主要里程碑時更新：新增版面、新增大型功能、專案結構改變。
- 一般修正、微調、文件更新不加進時間軸。
- 修改時間軸後，以 Mermaid 實際解析並繪製一次，確認能畫出。

## 步驟

1. 讀取 `docs/變更紀錄.md`，找到當月的月份節。
2. 依上述格式寫入條目。
3. 與該步其他檔案一起 commit。
