# 詞彙表維護規則

檔案：`docs/詞彙表.md`（repo 根目錄 `C:\Users\oright\Desktop\沙龍\DM`）

## 何時收錄

- 回報、docs 文件或 skill 中，第一次使用詞彙表沒有的技術術語時。
- 要使用某個縮寫時，該縮寫必須先收進詞彙表；沒收錄的縮寫改寫成完整說法。
- 一般日常用語、產品名稱、品牌名稱不收錄。

## 寫在哪裡

- 放進最符合的既有分類表格。
- 沒有合適分類時，在檔案最後新增分類（`## 分類名稱` ＋ 表格），並在回報中說明新增了分類。
- 已收錄的術語不重複收錄；解釋需要更新時直接修改原列。

## 條目格式

- 表格列：`| 術語 | 白話解釋 |`。
- 英文術語寫成 `中文（英文）` 或保留原文；縮寫寫成 `縮寫（全名）`。
- 白話解釋只寫一句，讓不熟軟體工程的人不查資料就能懂。
- 解釋中不得使用其他未收錄的術語；必須用到時，同時收錄該術語。
- 有助理解時，可在解釋後補一個本專案的實際例子。

## 搭配使用

- 回報或文件中第一次出現該術語時，括號內附同一句白話解釋。
- 收錄詞彙表的那一步，詞彙表與該步其他檔案一起 commit。

## 步驟

1. 搜尋 `docs/詞彙表.md`，確認術語是否已收錄。
2. 未收錄時，依上述格式寫入對應分類。
3. 與該步其他檔案一起 commit。
